# Uso responsável de inteligência artificial

O projeto AgroConnect foi desenvolvido com auxílio de ferramentas de IA para planejamento visual, revisão estrutural, sugestões de conteúdo e programação inicial. O codigo foi compreendido e revisado pela equipe.

A identidade da interface foi orientada para uma direção editorial rural original: títulos com Bricolage Grotesque, cores terrosas, hierarquia assimétrica, linhas e superfícies simples. Isso não significa que o software tenha sido escrito sem assistência de IA.

As composições visuais fotorrealistas usadas como ilustrações não são fotos documentais de produtores reais. O site indica que os perfis e valores são fictícios e usa dados públicos com fontes nomeadas.

O funcionamento depende de HTML, CSS e JavaScript. Todo o cadastro e os pedidos são demonstrações locais no navegador.
